👩‍💻 About Me
I'm an MCA graduate transitioning into cybersecurity, with a background in Physics and a strong interest in application security, vulnerability assessment and penetration testing (VAPT), network security, and security operations.

I recently completed five months of hands-on cybersecurity training and earned the Offenso Certified Security Professional (OCSP) certification. Through structured learning and practical labs, I've been building familiarity with security testing workflows, common web and API vulnerabilities, network reconnaissance, Linux, and SIEM fundamentals.

I enjoy understanding the why behind a vulnerability—not just memorizing commands—and documenting what I learn in a clear, repeatable way.
- 🛡️ Focus areas: Web application security, API testing, VAPT, network security, and SOC/SIEM fundamentals
- 🧪 Practical learning: Security labs, vulnerability analysis, and tool-assisted testing in authorized environments
- 🧰 Tools explored: Burp Suite, Nmap, Wireshark, Postman, Kali Linux, Splunk, Wazuh, and more
- 🎓 Education: Master of Computer Applications (MCA); Bachelor's degree in Physics
- 🌱 Currently building: Deeper practical skills, clear security documentation, and portfolio projects
- 🤝 Open to: Entry-level cybersecurity opportunities, mentorship, and collaborative learning
I use security tools only in environments where I have permission to test.
